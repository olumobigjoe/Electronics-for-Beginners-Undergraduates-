# ⚡ Electronics for Beginners

## Interactive Electronics Learning Laboratory

Electronics for Beginners is a centralized learning portal that brings together eight interactive electronics learning modules into one easy-to-use platform.

### Learning Modules

1. 🔧 Electronic Components
2. 📏 Measurements & Instrumentation
3. ⚡ Electrical Fundamentals
4. 🔌 Diodes & Rectifiers
5. 🔬 Transistors & Amplifiers
6. 💡 Logic Gates
7. 🧮 Circuit Analysis
8. 💻 Digital Electronics

### Recommended Learning Path

Electrical Fundamentals → Electronic Components → Measurements & Instrumentation → Circuit Analysis → Diodes & Rectifiers → Transistors & Amplifiers → Logic Gates → Digital Electronics

## Run Locally

```bash
git clone https://github.com/olumobigjoe/Electronics-for-Beginners.git
cd Electronics-for-Beginners
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

For macOS/Linux:

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## Deployment

Upload these three files to the GitHub repository:

```text
Electronics-for-Beginners/
├── app.py
├── requirements.txt
└── README.md
```

Deploy `app.py` using Streamlit Community Cloud.
